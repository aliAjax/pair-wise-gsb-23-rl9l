# hxwl-09 半导体洁净室巡检

洁净等级限值版本管理 + 粒子计数巡检判定看板。

## 技术栈

React + Vite + TypeScript + CSS（无后端，数据持久化在浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109；`npm run build` 产出 dist。

## 功能

### 管理员 · 限值版本台

- 按 ISO 5 / ISO 6 / ISO 7 / ISO 8 维护 0.3μm、0.5μm、5.0μm 三个通道上限（粒/m³，初值取 ISO 14644-1:2015）
- 只能“新建草稿 → 修改 → 发布”：草稿不参与巡检判定，任何记录都不会引用草稿
- 同一时刻仅允许一份草稿，可放弃；发布必须填写发布说明
- 已发布版本冻结不可改；再次变更新建更高版本号，历史版本可随时展开查看限值

### 巡检员 · 巡检判定台

- 选择房间（带出 ISO 等级）与已发布的判定版本（默认当前生效，可选历史版本），录入三通道计数
- 逐通道实时显示上限、差值与越界状态；提交后任一项超限即判“超限”，自动进入右侧异常区并列出越界项（实测 / 上限 / 超出值）
- 异常区与台账中任意记录可发起“补录修正”：原记录保留不变，另建一条修正记录，强制填写修正原因，并锁定原房间与原判定版本

### 追溯保证

- 每条巡检记录在提交瞬间复制一份当时的 `limitsSnapshot`（三通道上限），并记录版本号、越界通道、结论与时间
- 发布新版本、改限值都不会影响旧记录：旧记录永远显示“按 vN 判定”及当时的限值和结论；若该版本已非当前生效，标注“历史版本”
- 修正记录关联原记录，可互相跳转
- 版本、草稿、记录、巡检员姓名均存 localStorage（`hxwl09.state.v1`），重开页面后版本与记录仍对得上；清除站点数据回到内置示例状态
